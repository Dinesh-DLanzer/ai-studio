# AI Studio Premiere Panel Icons

This directory contains panel icons declared in `manifest.json`.

## Required Assets
- `icon-24.png`: 24x24 px standard resolution (scale: 1)
- `icon-24@2x.png` or 48x48 px asset (scale: 2) for high-DPI / Retina displays.

## Theme Variants
Adobe UXP supports light and dark theme icons. In `manifest.json`, `"theme": ["all"]` is configured to use this icon across dark, darkest, light, and lightest themes, or individual variants (`icon-dark.png`, `icon-light.png`) can be added when final branding assets are prepared.

For local development and initial packaging, a minimal valid 24x24 PNG placeholder is provided alongside this documentation.
