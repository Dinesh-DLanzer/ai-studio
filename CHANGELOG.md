# Changelog

## 0.1.0
First public release.
- Producer chat (Tara), Story.md to shot and asset lists, production checklist and Generate all.
- Price-approval safety: budget gate, 130% stop-loss, 3 attempts per shot, proposals approved by a human.
- Providers set up inside the app (no `.env`): ordered model chains with fallback; keys in the OS keychain.
- Review & Export video editor: timeline, trim, split, 36 transitions, text, music, MP4 export.
- Test projects (free, simulated) and real projects; export, import, favorite and archive projects.
- MCP server and HTTP API with revocable keys; live API reference in Help.
